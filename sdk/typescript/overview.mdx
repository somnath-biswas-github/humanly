# TypeScript SDK

The canonical package name is `@humanlyai/sdk`. The npm-published `0.1.0`
targets the hosted API, so use the checked-in `0.1.1-oss.0` prerelease source
with OSS v0.1:

```bash
(cd packages/sdk && npm ci && npm run build && npm pack --pack-destination ../..)
npm install ./humanlyai-sdk-0.1.1-oss.0.tgz
```

```ts
import { HumanlyClient } from "@humanlyai/sdk";

const client = new HumanlyClient({
  apiKey: process.env.HUMANLY_API_KEY!,
  baseUrl: "http://localhost:5000",
});

const agents = await client.listAgents();
const run = await client.triggerRun({ suiteId: "suite_xxx" });
const report = await client.waitForRun(run.id);
```

The client exposes create/list methods for agents, connectors, and suites;
trigger/get/list methods for runs; report polling; persona listing; and
create/get/list methods for baselines.

The source in `packages/sdk` is built and packed in CI.
