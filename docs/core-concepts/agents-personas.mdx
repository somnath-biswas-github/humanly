# Agents and personas

An **agent** is a logical record for the AI system being tested. Its network
location is stored separately in an AgentConnector so the same logical agent can
use different endpoints.

Create an agent with `POST /v1/agents` and list agents with `GET /v1/agents`.

The legacy suite API exposes one built-in starter persona through
`GET /v1/personas`; its smoke reports identify it as `Curious customer`.
This legacy route does not generate persona-driven dialogue.

For adaptive users, configure `persona.name` and `persona.description` inside a
[conversation definition](../conversational-testing.md). In synthetic mode the
simulator uses this persona and the scenario to generate actual messages.
It does not receive the evaluator's criteria. The standalone CLI does not need
an agent or persona database record.

See [test suites](test-suites.mdx) and
