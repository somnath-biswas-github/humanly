# Regression baselines

A baseline stores the score from a completed run and a permitted regression
threshold.

Create one:

```http
POST /v1/baselines
Authorization: Bearer <HUMANLY_API_KEY>
Content-Type: application/json

{
  "name": "Known passing run",
  "runId": "run_xxx",
  "threshold": 0
}
```

Pass the returned baseline ID when starting another run:

```json
{
  "suiteId": "suite_xxx",
  "baselineId": "baseline_xxx"
}
```

The report includes `baselineDelta` and `baselineBreach`. With a threshold of
zero, a score drop from 1 to 0 produces a breach.

Run `npm run demo` to exercise this exact flow.
