# Test suites

This page describes the existing default single-turn suites. For scripted
multi-turn L1–L5 tests, use the separate [workflow runner](../workflow-evaluation.md).

A suite binds:

- A logical agent
- An AgentConnector
- A test goal sent as the user message
- A conversation count from 1 to 100
- An optional starter persona ID
- Optional descriptive success criteria

Humanly OSS v0.1 runs the same one-turn goal for each requested conversation and
applies the deterministic `non_empty_response` check.

Create a suite with `POST /v1/suites`, then start it with:

```json
{
  "suiteId": "suite_xxx"
}
```

These legacy suites do not execute synthetic users or grade the descriptive
success-criteria field. Use [conversation definitions](../conversational-testing.md)
for scripted/synthetic multi-turn execution with weighted criteria and thresholds,
or [RAG suites](../rag-evaluation.md) for reference-based answer evaluation.
These are distinct contracts, not interchangeable payloads for `POST /v1/runs`.
