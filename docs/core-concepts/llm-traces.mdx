# LLM traces

The default OSS connector path does not ingest or evaluate Studio's general LLM
trace-scoring format. Its base request/response is documented in
[AgentConnectors](connectors.mdx).

The separate [workflow runner](../workflow-evaluation.md) does ingest and
evaluate versioned structured runtime events for L1–L5. These events are stored
with the report and shared with Studio's workflow evaluator. They are not a
general-purpose LLM token/latency tracing service. Do not assume arbitrary
framework trace fields will be scored without mapping them to that contract.
