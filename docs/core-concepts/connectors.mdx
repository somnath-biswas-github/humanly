# AgentConnectors

An AgentConnector stores the endpoint and optional forwarding authentication
for an AI agent.

Humanly sends a POST body with:

```json
{
  "message": "The suite test goal",
  "conversationId": "run_xxx_conversation_1",
  "history": []
}
```

Supported response forms:

```json
{ "response": "..." }
```

`message` and `output` keys are also accepted, as is non-empty plain text.

Connector authentication can forward a bearer token or `X-API-Key`. Treat
connector credentials as secrets.

Private, loopback, link-local, and reserved targets are blocked by default.
Only set `HUMANLY_ALLOW_PRIVATE_CONNECTORS=true` for deliberate local testing.
Production deployments should also restrict outbound network access.

See the [setup guide](../guides/agent-connector-setup.mdx).
