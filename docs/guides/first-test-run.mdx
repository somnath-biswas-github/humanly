# First test run

This demo verifies **connector smoke testing and baseline comparison**.
It deliberately detects an empty response, not subtle behaviour or RAG defects.
For a provider-free workflow correctness example or synthetic-user evaluation,
start with [choose your test](../choose-your-test.md).

To run the smoke demo:

```bash
cp .env.example .env
# Set HUMANLY_API_KEY in .env.
npm run demo
```

It:

1. Starts Humanly OSS, PostgreSQL, and the included local HTTP agent.
2. Creates an agent, connector, and passing suite.
3. Runs the suite and saves its score as a baseline.
4. Runs a second suite whose agent response is intentionally empty.
5. Confirms `non_empty_response` failed and `baselineBreach` is true.
6. Writes both reports to `demo-output/report.json`.

The intentional failed check is expected; the command exits successfully only
when Humanly detects it.

See the committed [example report](../../examples/example-evaluation-report.json).
