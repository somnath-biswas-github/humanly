# AgentConnector setup

First create a logical agent:

```bash
curl -X POST http://localhost:5000/v1/agents \
  -H "Authorization: Bearer $HUMANLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"My agent"}'
```

Then create its connector:

```bash
curl -X POST http://localhost:5000/v1/connectors \
  -H "Authorization: Bearer $HUMANLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production connector",
    "agentId": "agent_xxx",
    "endpointUrl": "https://agent.example.com/chat",
    "authType": "bearer",
    "authValue": "replace-with-agent-token",
    "timeoutMs": 30000
  }'
```

Supported `authType` values are `none`, `bearer`, and `api_key`.

Humanly validates HTTP(S) URLs and blocks private/reserved targets unless local
testing is explicitly enabled. Connector responses must follow the
[AgentConnector contract](../core-concepts/connectors.mdx).
