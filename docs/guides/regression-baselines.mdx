# Regression baseline workflow

1. Run a suite against a known-good agent version.
2. Create a baseline using that completed `runId`.
3. Trigger later runs with the returned `baselineId`.
4. Poll `GET /v1/runs/:id`.
5. Retrieve `GET /v1/runs/:id/report`.
6. Block deployment when `baselineBreach` is true.

A threshold is the allowed score decrease. With baseline score `1`:

| New score | Threshold | Breach |
| --- | --- | --- |
| 1 | 0 | No |
| 0 | 0 | Yes |
| 0 | 1 | No |

The included demo verifies the zero-threshold breach path.
