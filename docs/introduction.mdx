# Humanly OSS

> Standalone scripted workflows and scripted conversations are temporarily
> disabled. Use adaptive synthetic-user testing or RAG. Scripted capabilities
> described below are archived. See [availability](feature-availability.md).

Humanly is an AI-agent evaluation and regression-testing product family.

- **Humanly OSS** is the self-hosted AGPL engine in this repository.
- **Humanly Studio** is the proprietary hosted visual product at
  [humanly.ai](https://humanly.ai).

Humanly OSS offers synthetic-user conversations, conversational RAG,
standalone semantic RAG evaluation, and a legacy connector smoke
test. [Choose your test](choose-your-test.md) before configuring a runner.

Adaptive conversations can include deterministic L1–L5 runtime checks.
The separate [workflow evaluation](workflow-evaluation.md) guide is archived;
its scripted entry points are disabled.

## Included in v0.1

For measured results and their limits, see the
[Humanly OSS vs DeepEval live pilot](live-pilot-report.md), including expected
verdicts, model requests, costs and the full run history.

- Docker Compose deployment with PostgreSQL
- Automatic versioned migrations
- API-key authenticated REST API
- HTTP AgentConnector protocol
- Deterministic `non_empty_response` evaluation
- Adaptive synthetic-user conversations with configurable criteria,
  thresholds, budgets and synthetic-report replay
- Conversational RAG with independent references and turn-linked evidence
- Standalone semantic RAG evaluation with your own judge provider
- Reports and regression baselines
- OSS-compatible TypeScript SDK source
- CLI and Python SDK source

## Not included in v0.1

The OSS release does not include the Studio interface, Studio’s broader
evaluation catalog, general LLM trace analysis, webhooks, teams, or billing.
Full Studio/OSS configuration interchange is not implemented.
Similar testing concepts do not guarantee identical scores.
