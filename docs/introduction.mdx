# Humanly OSS

Humanly is an AI-agent evaluation and regression-testing product family.

- **Humanly OSS** is the self-hosted AGPL engine in this repository.
- **Humanly Studio** is the proprietary hosted visual product at
  [humanly.ai](https://humanly.ai).

Humanly OSS v0.1 connects to an HTTP agent, sends a one-turn test goal, evaluates
whether the agent returned a successful non-empty response, stores a report, and
compares runs with saved baselines.

The separate [workflow evaluation](workflow-evaluation.md) path supports scripted
multi-turn L1–L5 tests with runtime evidence, shared deterministic checks, saved
reports and explicit pass/fail/inconclusive gates.

## Included in v0.1

- Docker Compose deployment with PostgreSQL
- Automatic versioned migrations
- API-key authenticated REST API
- HTTP AgentConnector protocol
- Deterministic `non_empty_response` evaluation
- Scripted L1–L5 workflow evaluation through API and CLI
- Reports and regression baselines
- OSS-compatible TypeScript SDK source
- CLI and Python SDK source

## Not included in v0.1

The OSS release does not include the Studio interface, LLM-generated multi-turn
synthetic users, Studio’s broader LLM evaluation catalog, RAG evaluation, general LLM trace
analysis, webhooks, teams, or billing.

Start with the [quick start](quickstart.mdx), then run the
[included evaluation](guides/first-test-run.mdx).
