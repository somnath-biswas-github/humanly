# Humanly OSS v0.1.0

Humanly OSS v0.1.0 is the first self-hosted developer release of Humanly’s
agent-evaluation engine.

## Included

- Docker Compose deployment with PostgreSQL
- Automatic versioned database migrations
- Readiness-aware `/health` endpoint
- API-key authenticated REST API
- HTTP AgentConnector protocol
- Deterministic non-empty-response evaluation
- JSON reports and regression baselines
- OSS-compatible `@humanlyai/sdk@0.1.1-oss.0` prerelease source
- CLI and Python SDK source packages
- Reproducible demo with a passing baseline and intentional failed check
- CI for builds, tests, documentation links, Docker, migrations, health, SDKs,
  and CLI

## Project status

This is a beta `0.x` release. The Docker/API path and starter evaluator are
usable, but the richer multi-turn synthetic-user engine and Studio evaluation
catalog are not included in this release.

The npm-published `@humanlyai/sdk@0.1.0` targets the hosted API. Build and
install the checked-in `0.1.1-oss.0` source for this self-hosted release.

## Quick start

```bash
git clone https://github.com/somnath-biswas-github/humanly.git
cd humanly
cp .env.example .env
# Set HUMANLY_API_KEY to a long random value.
docker compose up --build
```

Then verify `http://localhost:5000/health`.

## Upgrade and compatibility

There is no earlier stable release to migrate from. Future `0.x` releases may
change APIs; breaking changes will be documented in the changelog.
